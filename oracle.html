Compute / VM / Bare Metal / Dedicated Host

Il servizio Compute (OCI) fornisce capacità di calcolo on‑demand per applicazioni web, database, batch e AI/ML. Le istanze si basano su shape che definiscono OCPU, memoria, storage e banda di rete.

  • Virtual Machine (VM): ambiente isolato che gira su hypervisor; flessibile e adatto a workload generici.
  • Bare Metal: server fisico dedicato a un solo tenant, ideale per HPC, database e carichi I/O intensivi.
  • Dedicated VM Host: hardware riservato dove eseguire solo le tue VM per isolamento a livello host e compliance.

Shapes, Vertical Scaling e Autoscaling

Shape: modello che definisce risorse (OCPU, memoria, storage, rete). Le shape influenzano prestazioni e costi.

Vertical Scaling: cambiare la shape di una VM per aumentare o ridurre OCPU e memoria (in OCI richiede l'arresto dell'istanza).

Autoscaling: scale‑out/scale‑in automatico di istanze in un pool basato su metriche o schedule, utile per applicazioni stateless.

Storage: Block, File, Object

  • Block Volume: dischi persistenti di rete (snapshot, replica, backup), adatti a database e workload I/O intensivi.
  • File Storage: filesystem condiviso (NFS) con semantica POSIX, accessibile da più istanze.
  • Object Storage: storage a scala Internet per dati non strutturati (bucket/oggetti), accessibile via API HTTP(S).

Virtual Cloud Network (VCN)

  • Rete privata virtuale in OCI
  • Configurazione RFC 1918 (10.0.0.0/16 consigliato)
  • Subnets pubbliche e private
  • Gateway per Internet, NAT e Service Gateway

Schema VCN: Public / Private Subnet

Schema semplificato del VCN: subnet pubbliche espongono risorse tramite Internet Gateway; subnet private contengono backend protetti, accessibili tramite NAT o LB.

Identity and Access Management (IAM)

Flusso: Utenti → Gruppi → Policy → Compartimenti → Risorse

  • Identity Domains: Container per utenti e configurazioni
  • Compartimenti: Isolamento e controllo accesso
  • Policy: Definiscono permessi granulari

Best practice: principio del minimo privilegio, uso di MFA e separazione tra account amministrativi e operativi.

Region, Availability Domain, Fault Domain

Regione (Region): area geografica che contiene uno o più data center logici con servizi cloud completi. Scegli la regione per latenza, compliance e sovranità dei dati.

Availability Domain (AD): data center logico isolato all'interno di una regione per ridurre il rischio di guasti simultanei.

Fault Domain (FD): raggruppamento logico di hardware all'interno di un AD per confinare impatti di manutenzione e failure.

Virtual Cloud Network (VCN), Subnet e CIDR

VCN è la rete virtuale di base; una subnet copre un blocco CIDR e può essere pubblica o privata.

CIDR: notazione A.B.C.D/x che definisce la dimensione del blocco IP; OCI raccomanda l'uso di intervalli RFC1918 per reti private.

Indirizzi IP: Pubblico vs Privato

  • IP Privato: comunicazione all'interno del VCN o verso reti collegate (VPN, FastConnect); non raggiungibile da Internet.
  • IP Pubblico: raggiungibile da Internet, tipicamente assegnato a VNIC in subnet pubbliche o a risorse esposte esternamente.
